Write the funniest one-line patch note for a bug in real life or human biology, 160 characters max. Free entry, open 72 hours, and the top 5 places split the reward pool equally.

## The entry

> v2.1.0: fixed a bug where the brain replayed your most embarrassing moment at 3 a.m. It now replays it at 3 p.m. in front of witnesses.

One line, 135 characters. A real release note in terse engineering register: version number, a specific recognisable bug of the body (the 3 a.m. cringe replay), and a fix stated as if it shipped — the fix relocates the bug somewhere worse, in front of witnesses.

## Run it

```sh
node --experimental-strip-types main.ts
```

Writes the entry to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). Node 22 stdlib only, no dependencies.
